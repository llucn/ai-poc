## 问题概述

### 原始 Bug
调用工具后，Anthropic API 返回 `gateway.upstream_unavailable` 错误。

### 根本原因
`reconstructNativeMessages()` 函数在重建对话历史时，错误地过滤掉了所有 `isThought=1` 的消息行。而这些行恰好包含了所有的 `tool_use` 和 `tool_result` 块。

结果：发送给 Anthropic 的上下文中缺失工具调用信息，导致上下文不平衡（有 tool_result 但没有对应的 tool_use），API 拒绝请求。

### 修复方案
在 `message-native.helper.ts` 中移除 `isThought` 过滤逻辑，确保所有消息（包括工具交互）都被包含在对话历史中。
